# Evaluation design

Owns public cases, protected requirement categories, gates, baseline comparison,
production-contract reachability, and effective-role-prompt reachability inside
`EvalSpec`. Every request-owned privacy requirement must remain an exact,
positive-case protected category; broader categories may only supplement it.
The incoming draft and all other Stage inputs are immutable. A transported
final blueprint must use a new attempt-scoped artifact path with exact lineage
to the draft; evaluation design must never overwrite or reuse an input path.
